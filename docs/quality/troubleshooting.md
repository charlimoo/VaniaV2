# Troubleshooting

Use this page for recurring local and runtime problems.

## Areas To Cover

- Frontend build or TypeScript errors
- Backend migration failures
- Missing environment variables
- Docker service startup issues
- Celery worker failures
- Agent runtime errors
- Canvas renderer mismatches
- Role/access surprises

## Entry Format

Each troubleshooting entry should include:

- Symptom
- Likely cause
- How to confirm
- Fix
- Related paths
