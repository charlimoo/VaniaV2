# Manual QA

Manual QA is important for flows that cross backend, frontend, role, billing, and runtime state.

## Suggested Checklists

- Visitor chat flow
- Expert chat flow with selected visitor
- Expert profession-specific agent discovery
- Canvas hydration
- Canvas edit and persistence
- Demo access and locked/hidden canvas modes
- Billing upgrade/downgrade behavior
- Mobile chat/canvas switching

## Documentation Rule

When a bug requires manual reproduction, add the reproduction path and expected state transitions here or on a related feature page.
