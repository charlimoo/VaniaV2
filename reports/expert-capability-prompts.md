# Expert Capability Test Prompts

Use these with `backend/definitions/agents/expert.py`.

Select a visitor before testing. Replace placeholders like `<case_id>`, `<task_id>`, `<test_id>`, `<file_id>`, `<attachment_id>`, and `<medication_id>` with values returned by earlier prompts.
